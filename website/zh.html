你的桌面，一个项目一个

那些琐事

八个步骤，一天十遍。

每次坐下来动一个项目，都是同一套流程。再乘以几十个项目，每天如此，年复一年。

八步交给 loadcli。你只做一步。

  • 打开终端
  • cd 到正确的目录
  • 启动 CLI
  • 挑选模型和 effort
  • 打开浏览器
  • 翻出部署地址
  • 新建一个桌面，免得弄乱其他的
  • 拖动并调整窗口大小
  • 双击卡片

一键

双击之后发生了什么。

每个窗口都会被验证。如果某个没落到该在的位置，loadcli 会先纠正，再把控制权交还给你。

01

你双击一下

点项目的卡片。或者从菜单栏启动，连主窗口都不用打开。

02

桌面诞生

在你选定的显示器上新建一个 Space。其他桌面保持原样，纹丝不动。

03

终端开好就绪

已经在项目目录里，你的 CLI 正在运行，用的是这个项目该用的模型和 effort。

04

一切各就各位

浏览器打开部署地址、一个 Finder 文件夹，或者只让终端全屏。焦点最终停在你要敲字的地方。

与众不同之处

卡片就住在项目文件夹里。

没有项目数据库。每个文件夹里带着一个 LOADCLI.md，那个文件就是卡片。loadcli 遍历你登记过的文件夹，找出这些文档，再按文档里写的内容生成网格。

 acme/LOADCLI.md
---
loadcli: 1
nome: Acme Site
grupo: 客户
icone: cart.fill
cor: "#3B82F6"
repositorio: github.com/acme/site
url: app.acme.com
cli: claude
modelo: opus
esforco: xhigh
---

启动
  • 绝不写入绝对路径项目文件夹就是文件所在之处。同一份文档在任何 Mac、任何用户名下都能用。
  • 同步一下就好把项目文件夹放进 Google Drive 或 ownCloud。你所有的 Mac 都会显示同一份、始终最新的卡片。
  • 文件是你的用你的编辑器改它，用 git 管它。你添加的键和 markdown 正文，在每次重写后都会保留。
  • 秒开上一次扫描会被缓存。窗口立刻出现，新卡片稍后浮现。

为用 AI 写代码的人而做

每个项目，配自己的大脑。

这个用 Claude Code，那个用 Codex，第三个跑你自己的脚本。模型和 effort 就写在项目的文件里，所以一打开就是对的状态。不用记任何参数。

Claude Code

按项目设定模型和 effort。命令会照你配置的样子拼好。

fableopussonnethaikuxhighultracode

Codex

同样的思路，用 Codex 自己的参数。想改的话，启动时改也行。

gpt-5.6-solgpt-5.5minimalhigh

自定义命令

任何能在 shell 里跑的东西。loadcli 负责 cd，然后执行。

npm run devdocker compose upmake watch

每张卡片都有自己的图标和颜色。扫一眼十秒，就能找到要的那个项目。

难的地方

不用你关闭 SIP，也能新建桌面。

在现代 macOS 的 App 里，通过私有 API 创建 Space 是行不通的。这正是那些平铺窗口工具要你关掉系统完整性保护的原因。

loadcli 做的是人会做的事：通过辅助功能 API 驱动 Mission Control 的 + 按钮，按显示器标识定位屏幕，再点击新桌面的缩略图。每一步都会先验证结果再继续。

SIP 保持开启。没有守护进程。没有内核 hack。

细节

其余那些你每天都会用到的东西。

快速搜索

边输入，含匹配结果的文件夹会自动展开。清空后，它们又全部折叠。

最近

你最近打开过的项目，从新到旧。

文件夹

按文档里的 grupo 键分组。默认折叠，方便一眼扫过。

多显示器

按项目固定显示器，或者让 loadcli 每次都问你。

终端字号

它替你把字号调大，次数由你设定。

菜单栏

不用打开主窗口，也能启动任意项目。

自检

loadcli --doctor 会在每块显示器上检查桌面机制。

100% 原生

SwiftUI，没有 Electron。秒开，几乎不占内存。
