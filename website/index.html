03What makes it differentLOADCLI.md

The card lives inside the project folder.

There is no project database. Each folder carries a LOADCLI.md, and that file is the card. loadcli walks the folders you registered, finds those documents, and builds the grid from what they say.

acme/LOADCLI.md
---
loadcli: 1
nome: Acme Site
grupo: Clients
icone: cart.fill
cor: "#6C4DF6"
repositorio: github.com/acme/site
url: app.acme.com
cli: claude
modelo: opus
esforco: xhigh
---

05The hard partSIP ✓

It creates desktops without you disabling SIP.

Creating a Space through a private API does not work in a modern macOS app. That is why tiling tools ask you to turn System Integrity Protection off.

loadcli does what a person would do: it drives Mission Control's + button through the Accessibility API, targets the monitor by its display id, and clicks the new desktop's thumbnail. Always verifying the result before moving on.

SIP stays intact. No daemon. No kernel hack.
