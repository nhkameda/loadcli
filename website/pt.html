Suas mesas, uma por projeto

O tédio

Oito passos, dez vezes por dia.

Toda vez que você senta para mexer num projeto é o mesmo ritual. Multiplicado por dezenas de projetos, todo dia, a vida inteira.

O loadcli faz os oito. Você faz um.

  • abrir o Terminal
  • cd na pasta certa
  • subir o CLI
  • escolher o modelo e o effort
  • abrir o navegador
  • achar a URL do deploy
  • criar uma mesa nova pra não bagunçar as outras
  • arrastar e redimensionar as janelas
  • clicar duas vezes no card

Um clique

O que acontece quando você clica duas vezes.

Cada janela é verificada. Se alguma não caiu onde devia, o loadcli corrige antes de te devolver o controle.

01

Você clica duas vezes

No card do projeto. Ou pelo menu da barra de status, sem nem abrir a janela principal.

02

A mesa nasce

Uma área de trabalho nova, no monitor que você escolheu. Suas outras mesas continuam como estavam.

03

O terminal abre pronto

Já na pasta do projeto, com o seu CLI rodando, no modelo e no effort que aquele projeto pede.

04

Tudo assume o lugar

Navegador no deploy, uma pasta no Finder, ou só o terminal em tela cheia. O foco termina onde você vai digitar.

O diferencial

O card mora dentro da pasta do projeto.

Não existe banco de dados de projetos. Cada pasta carrega um LOADCLI.md, e esse arquivo é o card. O loadcli varre as pastas que você cadastrou, encontra os arquivos e monta a grade a partir do que está escrito neles.

 acme/LOADCLI.md
---
loadcli: 1
nome: Acme Site
grupo: Clientes
icone: cart.fill
cor: "#3B82F6"
repositorio: github.com/acme/site
url: app.acme.com
cli: claude
modelo: opus
esforco: xhigh
---

Iniciar
  • Nenhum caminho absolutoA pasta do projeto é onde o arquivo está. O mesmo documento funciona em qualquer Mac, com qualquer nome de usuário.
  • Sincronize e prontoColoque sua pasta de projetos no Google Drive ou no ownCloud. Todos os seus Macs mostram os mesmos cards, sempre atualizados.
  • O arquivo é seuEdite no seu editor, versione no git. As chaves que você acrescentar e o texto em markdown sobrevivem a qualquer regravação.
  • Abre na horaA última varredura fica em cache. A janela pinta imediatamente e os cards novos aparecem um instante depois.

A parte difícil

Cria mesas sem você desligar o SIP.

Criar uma área de trabalho por API privada não funciona num app moderno do macOS. É por isso que as ferramentas de tiling pedem para você desligar a proteção de integridade do sistema.

O loadcli faz o que uma pessoa faria: dirige o botão + do Mission Control pela API de Acessibilidade, mira o monitor pelo identificador de tela e clica no thumbnail da mesa nova. Sempre conferindo o resultado antes de seguir.

SIP intacto. Nenhum daemon. Nenhum hack de kernel.
